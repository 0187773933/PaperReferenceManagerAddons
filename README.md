# Paper Reference Manager Addons

## Addons

1. `prma` : generates OpenAlex graph and missing.xlsx
2. `prma server` : runs local 'exists' server
3. `prma snapshot` : creates local archive file
4. `prma yolo` : run doclayout yolo model on each pdf
5. `prma images` : generate individual images and a montage from figures and tables in each pdf
6. `prma ocr` : run ocr task on yolo blocks
7. `prma md` : generate markdown versions of each pdf
8. `prma text` : generate text versions of each pdf
9. `prma methods` : isolates methods sections of each pdf
10. `prma summarize` : runs summarization task on each pdf or section
11. `prma rollup` : generates a report from summarization tasks
12. `prma crawl` : attempts to crawl the OpenAlex graph
