# Mendeley Developer Account Setup

1. Sign In : https://dev.mendeley.com
2. Go To : https://dev.mendeley.com/myapps.html
3. Register a new app
4. Fill Out `Application Name`
5. Fill Out `Description`
6. Fill Out `Redirect URL`
	- set it to `http://localhost:5934`
7. Click/Check "I accept the new Terms and Conditions"
8. Click "Generate secret" button
9. Copy and save the generated secret key into config.yaml
10. Click Submit
11. On the left , under "My applications" , copy the "ID" of the new application ( 5 digit value ) , and save into config.yaml
